# Lili's crochet

App personal para gestionar mis proyectos de crochet: contadores por sección,
cronómetro de sesiones, yarns, medidas, categorías, inventario, ideas y estadísticas.

## Cómo publicarla (resumen)

1. Sube todo este contenido a un repositorio de GitHub llamado, por ejemplo, `lilis-crochet`.
2. En el repo: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Cada vez que subas cambios a la rama `main`, se compilará y publicará sola.
4. La URL será algo como: `https://TU-USUARIO.github.io/lilis-crochet/`
5. Abre esa URL en el móvil y usa "Añadir a pantalla de inicio".

Tus datos se guardan en el propio navegador del móvil (localStorage), solo en ese dispositivo.
